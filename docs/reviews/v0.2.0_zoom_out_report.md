# v0.2.0 Initial Zoom Out Review

**Reviewer:** Skeptical Architect (`egm-zoom-out`)  
**Target:** `docs/specs/v0.2.0_export_and_hardening_spec.md` & v0.2.0 modifications

## Findings

### Finding 1: Prefix match bug grabs wrong file on direct export
- **Severity**: 🔴 Blocker
- **Affected Scope**: `electron/services/YtDlpRunner.ts` (lines 527–535)
- **Problem**: `files.find(f => f.startsWith(chosenBaseName))` scans shared `config.outputDir`. If directory has older `My_Clip (1).mp4` and user downloads `My_Clip.mp4`, alphabetical sorting matches `My_Clip (1).mp4` first. App reports older file as new download result.
- **Fix**: Check exact name: `path.parse(f).name === chosenBaseName`.

### Finding 2: Passlog cleanup skipped on error and scans full OS temp directory
- **Severity**: 🔴 Blocker
- **Affected Scope**: `electron/services/FfmpegRunner.ts` (lines 981–1051)
- **Problem**: Passlog cleanup runs after `await runFfmpegWithProgress`. If pass 1 or 2 fails or user cancels, function throws and cleanup never runs. Furthermore, cleanup calls `fs.readdirSync(os.tmpdir())`, which blocks the event loop on large temp folders.
- **Fix**: Delete targeted known file paths (`${passLogPrefix}-0.log`, `${passLogPrefix}-0.log.mbtree`) inside a `finally` block.

### Finding 3: WAV cleanup scattered across 10 callbacks instead of single try/finally
- **Severity**: 🟡 Major
- **Affected Scope**: `electron/services/StemRunner.ts` (lines 91–220)
- **Problem**: `cleanupTempWav` manually invoked in 10 different callback branches. If `extractOrNormalizeWav` aborts mid-stream, cleanup never runs.
- **Fix**: Await process execution inside `try { ... } finally { cleanupTempWav(); }`.

### Finding 4: Test suite tests internal duplicate functions and omits spec test #2
- **Severity**: 🟡 Major
- **Affected Scope**: `tests/self-check.test.mjs`, `v0.2.0_export_and_hardening_spec.md` line 78
- **Problem**: `self-check.test.mjs` re-implements `getNonCollidingFilePath` locally. Spec Patch D item 2 ("Unit tests for Premiere Pro XML sequence frame calculation rules") is missing.
- **Fix**: Add XML frame calculation tests and test real exports.

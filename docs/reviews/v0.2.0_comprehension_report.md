# v0.2.0 Comprehension Audit Report

**Reviewer:** Naive Reader (`egm-comprehension`)  
**Target:** `docs/specs/v0.2.0_export_and_hardening_spec.md`

### 1. High-Level Concept Paraphrase
This document specifies export path routing and reliability fixes for Vortex v0.2.0. Single-file exports will write directly to the user's selected destination directory without generating wrapping folders, while multi-file operations continue using dedicated subfolders. When a destination file name already exists, the system automatically appends an incrementing numeric counter `(1)`, `(2)` to avoid overwriting existing data. Additionally, four hardening fixes address leaked temporary audio files during stem extraction, crashes when analyzing audio-less video during silence detection, missing audio format extensions in video downloading, and regression test coverage.

### 2. Technical Implementation Paraphrase
A shared helper `getNonCollidingFilePath` in `electron/services/FileUtils.ts` resolves collisions by iteratively checking path existence with a ` (${counter})` suffix before returning an absolute file path. The export engine routes 1-file operations to `config.outputDir` directly and 2–4 file operations to `outputDir/${name}_${id}` subfolders. For system hardening, `StemRunner.ts` moves WAV cleanup to Promise scope to prevent disk leaks on error or simulated execution; `FfmpegRunner.ts` checks codec status and stream presence to throw an early user-facing error before running silence filters; `YtDlpRunner.ts` appends `.m4a`, `.flac`, `.opus`, and `.ogg` to its job directory search filter; and `tests/self-check.test.mjs` verifies path collision, silence detection guards, and XML frame calculation rules.

### Findings

#### 🔴 Blocker
1. **Undefined Premiere Pro XML Frame Calculation Specification**: Line 78 mandates unit tests for frame calculation rules without defining them.
2. **Ambiguous `hasAudioStream` Failure Fallback**: Spec instructs calling `hasAudioStream`, but does not define fallback behavior if probing corrupt files.

#### 🟡 Major
3. **Collision Suffix Stacking on Numbered Inputs**: Files named `Clip (1)` become `Clip (1) (1).mp4`.
4. **Missing Collision Strategy for Multi-File Output Directories**: No collision resolution when subfolder `${name}_${id}` exists.
5. **Missing WAV Cleanup on User Cancellation**: Behavior not defined if user aborts before Demucs finishes.

#### 🟢 Nit
6. **Undefined Domain Slang "pills"**: UI component jargon used without definition.
7. **Implicit Output Directory Creation**: Recursive creation behavior should be explicit.

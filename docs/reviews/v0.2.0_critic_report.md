# v0.2.0 Hostile Design Critique Report

**Reviewer:** Hostile Design Critic (`egm-design`)  
**Target:** `docs/specs/v0.2.0_export_and_hardening_spec.md` & Implementation

### Findings

#### 1. 🔴 Blocker: TOCTOU Concurrency Race Condition in Path Resolution
- **Affected Scope:** `FileUtils.ts` (lines 8–24)
- **Flaw:** `getNonCollidingFilePath` only checks `fs.existsSync(candidate)`. Two parallel jobs with the same title check before writing and claim the identical path, causing file overwrite or Windows `EBUSY` crashes.
- **Fix:** Add in-memory `reservedPaths` Set in `FileUtils` to reserve candidate paths during job lifetime.

#### 2. 🔴 Blocker: Flawed yt-dlp Output Matcher and Dead Extension Whitelist
- **Affected Scope:** `YtDlpRunner.ts` (lines 515–547)
- **Flaw:** In direct export mode, loose prefix matching matches `.json`, `.docx`, or older numbered video versions.
- **Fix:** Check `fs.existsSync(expectedOutputPath)` directly; enforce exact stem match and `mediaExts.has(ext)`.

#### 3. 🟡 Major: Orphaned `.part` Clutter on Direct Export Cancellation
- **Affected Scope:** `YtDlpRunner.ts` (lines 620–629)
- **Flaw:** On cancel, partial files remain in root export folder.
- **Fix:** Sweep `${chosenBaseName}*.part` and `.ytdl` on cancel.

#### 4. 🟡 Major: DOS Device Names and Trailing Dot/Space Failures
- **Affected Scope:** `FileUtils.ts`, `YtDlpRunner.ts`, `FfmpegRunner.ts`
- **Flaw:** Video titles matching Windows device names (`CON`, `PRN`, `AUX`, `NUL`) fail on disk write.
- **Fix:** Centralize `sanitizeBaseName` in `FileUtils.ts` and prefix reserved DOS names.

#### 5. 🟡 Major: Stems Buried 3 Subfolders Deep in Multi-File Presets
- **Affected Scope:** `StemRunner.ts`
- **Flaw:** Stems saved under `${jobFolder}/stems/htdemucs/${trackName}/` instead of flat in `${jobFolder}`.
- **Fix:** Flatten output into `${jobFolder}`.

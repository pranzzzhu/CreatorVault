# VORTEX (CreatorVault) v0.3.0 — Astryx Design System UI Migration Specification

This specification defines the complete, ground-up migration of Vortex's user interface from **daisyUI v5** to Meta's **Astryx Design System** (`@astryxdesign/core` + `@astryxdesign/theme-neutral` + `@stylexjs/stylex`), while retaining **Tailwind CSS v4** via Astryx's official token bridge (`@astryxdesign/core/tailwind-theme.css`) and full **Dark / Light Mode** support.

---

## 1. Objectives & Architectural Principles

1. **Zero daisyUI Footprint**: Uninstall `daisyui` (`^5.7.50`) and remove every daisyUI class (`btn`, `card`, `badge`, `toggle`, `join`, `menu`, `modal`, `dropdown`, `progress`, `alert`, `tooltip`, `bg-base-*`, `text-base-*`, `border-base-*`) across all 13 matching files in `src/`.
2. **Native Astryx Primitives & Frame-First Density**: Adopt Astryx's frame-first layout philosophy—replacing heavy nested card boxes with crisp structural frames, edge-to-edge dividers for dense lists (staged files, binary diagnostics, stem tracks), and accessible Astryx components (`Button`, `Badge`, `Switch`, `Dialog`, `Select`, `SegmentedControl`, `ButtonGroup`, `ProgressBar`, `Tooltip`).
3. **First-Class Dark & Light Mode**: Support seamless runtime switching between **Astryx Dark** and **Astryx Light** (`@astryxdesign/theme-neutral`), synchronized with `<XDSTheme>`, DOM `color-scheme` / `data-theme`, `localStorage` persistence, and Electron's native `setTitleBarOverlay` in `electron/main.ts`.
4. **Zero Regression on Desktop & Media Capabilities**:
   - Preserve Electron window drag strips (`.app-drag-region`, `.app-no-drag`).
   - Preserve native OS file drag-to-NLE pills (`.native-drag-pill` calling `window.vortexApi.startNativeDrag`).
   - Preserve custom sub-second dual-handle + window drag math in `TimeRangeSlider.tsx`.
   - Preserve WebAudio `AudioContext` phase-aligned multi-stem mixer in `JobQueueList.tsx`.
   - Preserve keyboard/mousewheel workspace zoom (`Ctrl +`, `Ctrl -`, `Ctrl 0`, `Ctrl + Wheel`).

## 3. Global Stylesheet & Cascade Layer Architecture (`src/index.css` & `index.html`)

### 3.1 Explicit CSS `@layer` Ordering (`src/index.css`)
Replace `@import "tailwindcss"; @plugin "daisyui";` and the two `@plugin "daisyui/theme"` blocks with Astryx's Tailwind v4 cascade layer setup:

```css
/* 1. Explicit cascade layer priority */
@layer reset, theme, base, astryx-base, astryx-theme, components, utilities;

/* 2. Tailwind v4 theme & preflight */
@import "tailwindcss/theme.css" layer(theme);
@import "tailwindcss/preflight.css" layer(base);

/* 3. Astryx Core, Neutral Theme, and Tailwind Token Bridge */
@import "@astryxdesign/core/reset.css";
@import "@astryxdesign/core/astryx.css";
@import "@astryxdesign/theme-neutral/theme.css";
@import "@astryxdesign/core/tailwind-theme.css";

/* 4. Tailwind v4 utilities */
@import "tailwindcss/utilities.css" layer(utilities);
```

### 3.2 Preserved Desktop & Utility Rules (`src/index.css`)
Keep only desktop-specific rules below the layer imports:
- `body` typography (`font-size: 13px`, `user-select: none`, `overflow: hidden`, `-webkit-font-smoothing: antialiased`)
- `.num`, `code`, `pre` tabular monospace font stack (`font-variant-numeric: tabular-nums`)
- `.app-drag-region` (`-webkit-app-region: drag`) and `.app-no-drag` (`-webkit-app-region: no-drag`)
- `.native-drag-pill` (`-webkit-user-drag: element; user-select: none; -webkit-app-region: no-drag;`)
- `.bg-checkerboard` (alpha matte preview background in `VectorizerModuleView.tsx`)

### 3.3 `index.html`
- Update `<html lang="en">` and `<body>` to remove `data-theme="antigravity-dark"` and `bg-base-100 text-base-content`, replacing with Astryx surface/text token classes (`bg-surface text-primary antialiased`).

## 4. Theme System & Electron Native Window Sync

### 4.1 Theme State & Persistence Migration
| File | Current Implementation | Astryx Target Implementation |
|---|---|---|
| `src/types/media.ts` | `export type ThemeMode = 'antigravity-dark' \| 'antigravity-light';` | Support `'dark' \| 'light'` (with backward-compatible coercion for persisted `'antigravity-dark'` $\rightarrow$ `'dark'` and `'antigravity-light'` $\rightarrow$ `'light'`). |
| `src/store/useJobStore.ts` | Defaults `themeMode: 'antigravity-dark'` in `vortex-job-store-v3`. | Default `themeMode: 'dark'`; add migration/hydration check so existing users with `'antigravity-dark'` or `'antigravity-light'` in `localStorage` automatically normalize to `'dark'` or `'light'`. |
| `src/App.tsx` | Sets `document.documentElement.setAttribute('data-theme', themeMode)`. | Wrap root shell in `<XDSTheme theme={neutralTheme} mode={resolvedMode}>`, set `document.documentElement.setAttribute('data-theme', resolvedMode)`, and set `document.documentElement.style.colorScheme = resolvedMode`. |
| `electron/main.ts` | Checks `theme === 'antigravity-light' \|\| theme === 'light'` and updates `setTitleBarOverlay`. | Keep check supporting both `'light'` and `'antigravity-light'`; align overlay background/symbol hex colors with Astryx Neutral dark/light surface tokens. |

### 5.2 File-by-File UI Refactor Plan

#### 1. `src/App.tsx` (Root Frame & Theme Provider)
- Wrap application in `<XDSTheme theme={neutralTheme} mode={themeMode}>`.
- Keep left `<SidebarRail />`, top `h-9 app-drag-region` window bar, scrollable main workspace (`max-w-4xl mx-auto`), and `<DiagnosticsPanel />` dialog.

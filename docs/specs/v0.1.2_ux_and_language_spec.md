# VORTEX (CreatorVault) v0.1.2 — UX Polish, Taskbar Progress & Simple Language Specification

## Summary of 6 Upgrades

1. **Dynamic Download Button (`StagingCard.tsx`):** Defaults to a clean **"Download"** button. Automatically changes to **"Cut & Download Clip"** when section trimming is toggled on, **"Download & Split Stems"** when stems are active, or **"Cut & Split Stems"** when both are active.
2. **Persistent Last-Used Folder (`useJobStore.ts`, `main.ts`, `preload.ts`):** Saves the user's most recently picked folder in `localStorage` (`vortex_last_output_dir`) and passes it into `dialog.showOpenDialog({ defaultPath })` so the folder picker always opens where the user last left off instead of resetting to `Downloads/Vortex_Exports`.
3. **Instant Byte-Range Clipping Without CPU Re-Encoding (`YtDlpRunner.ts`):** Restores `--remux-video mp4` for `<=1080p` and adds `--concurrent-fragments 4` so cutting 30 seconds out of a 40-minute video only downloads that 30-second slice in ~2–3 seconds.
4. **Native Windows Taskbar Progress Bar (`main.ts`):** Calls `mainWindow.setProgressBar(ratio)` across all 4 modules (`job:start`, `fixer:start`, `vector:start`, `converter:start`) so the Vortex taskbar icon shows a live green progress bar.
5. **Draggable Blue Clipping Window (`TimeRangeSlider.tsx`):** Lets the user grab and drag the blue middle highlight bar itself left or right to slide the entire clip window across the timeline while keeping its duration locked.
6. **Simple, Approachable Language Across All 4 Tabs (`SidebarRail`, `StagingCard`, `UrlCommandBar`, `FixerModuleView`, `VectorizerModuleView`, `ConverterModuleView`, `DiagnosticsPanel`, `JobQueueList`):** Replaces technical jargon with clear, everyday creator language.

## Detailed Implementation Plan

- Implement `updateWindowTaskbarProgress(progressPayload: JobProgressEvent)` and bind it to `job:progress` across all job types.

- Initialize and persist `outputDir` to `localStorage` key `vortex_last_output_dir`.

- Add `'window'` dragging mode with mouse offset tracking.
- Slide range while clamping inside `[0, duration]`.

- Update `StagingCard.tsx` download button label based on `trimEnabled` and `stemMode`.
- Change button text in `UrlCommandBar.tsx` to "Load Link" and "Loading...".

### Step 6: Approachable Language Across Sidebar, Fixer, Vectorizer, Converter & Queue
- Align titles, descriptions, and labels across all views with plain, user-friendly language.
